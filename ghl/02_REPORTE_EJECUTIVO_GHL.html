1. Arquitectura de Integración (Dual-Dispatch)

Para eliminar al 100% la fuga de prospectos al momento de hacer clic en WhatsApp, la web envía los datos en segundo plano hacia GoHighLevel (vía API v2 o Inbound Webhook) antes o simultáneamente a la apertura del chat de WhatsApp.

2. Endpoints Server-Side Activos

Endpoint Método Función Técnica
/api/ghl-webhook POST Puente principal que hace upsert a la API v2 de GHL y reenvía al webhook del workflow.
/api/lead POST Endpoint de captura con cola de respaldo y sanitización de datos.
/api/ghl-event POST Receptor de eventos de telemetría (clics en WhatsApp, aperturas de calendario, etc.).
